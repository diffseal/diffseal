# Diffseal v0.6.2-beta

Accuracy fixes from replaying 750 commits of 10 public Terraform repositories that earlier releases were not tuned on. On those commits, false BLOCKs fell from 2 to 0, the one table deletion that passed now blocks, and the three commits that ran out of memory now replay. Nothing moved toward BLOCK on the 675 commits measured for 0.6.1-beta. `docs/STATUS.md` has the numbers.

## Changes

- Workspaces. A root whose configuration picks its environment from `terraform.workspace` is evaluated once per workspace name it uses, up to 8, besides `default`. Reports and change records name the workspace each result came from.
- A `roots` mapping in `.diffseal.json` says which var-files, in order, and which workspace each root runs with. Diffseal reads it from the base of the change, so a pull request cannot change how it is reviewed. See `docs/guide/configuration.md`.
- Terragrunt. `inputs` with literal values, a local `terraform.source` and parent includes are read, and the root is evaluated with them. Anything that needs a command or another stack's outputs (`dependency`, `run_cmd`, `get_env`, generate blocks) is reviewed by name. Nothing is run.
- A git submodule bump that a root calls modules from is reviewed, naming the submodule and both commits.
- Deleting an API Gateway stage or a load balancer listener is reviewed.
- A removed resource with `skip_destroy = true` is no longer reported as lost.
- `moved` blocks into a module's `for_each` instances are matched.
- A container definition built from `jsonencode()` inside a string template shows its changes.
- An inline IAM policy is matched to its role, user or group by name without case, and through in-place renames.
- A change record over 900 KiB leaves out its lowest-risk resource rows and says how many, so it stays under the evidence service's upload limit.
- `.tf` symbolic links that no root reads, or that cannot be read, are reviewed.

## What to expect

A few more changes land in REVIEW: submodule bumps, deleted API stages and listeners, and changes in workspaces other than `default`. Repositories using Terragrunt or a `roots` mapping see fewer coverage REVIEWs.

## Upgrade notes

1. Change `diffseal/diffseal@v0.6.1-beta` to `diffseal/diffseal@v0.6.2-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.6.2-beta`.
2. Update the CLI with `npm install -g diffseal@beta`.
3. Optional: add a `roots` mapping to `.diffseal.json` if your var-files or workspaces live outside the root directory.

See CHANGELOG.md for all versions.
