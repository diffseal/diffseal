# Diffseal v0.4.0-beta

This release connects the Action to the Diffseal evidence service. The analysis and the gate are unchanged.

## Changes

- **Upload.** A trusted reusable workflow, `diffseal/diffseal/.github/workflows/upload.yml@v0.4.0-beta`, runs the Action in advisory mode and uploads a scrubbed change record to `api.diffseal.com`. GitHub's OIDC token identifies the workflow. Uploads are off by default, and the service accepts only trusted reusable workflows: this one, or one an organisation owner registers.
- **What is sent.** Commit metadata, root paths, resource addresses and actions, gate reasons and items, risks, control findings, access call sites and analysis notes. Never source files, Terraform configuration, plans, state or credentials.
- **Gate items.** The change record lists each risk, control, access, exception, coverage and policy finding as a structured `gate.items` entry, aligned with its reason text.
- **Exception links.** A blocked pull request comment links to an exception request on the service.
- **Offline verification.** `diffseal verify <folder>` checks a pack's file list, hashes, Ed25519 signature, key validity and, optionally, its account and period. It needs no network. This version bundles Diffseal's first public signing key, `ac566f5ee309c7e6`.

## Upgrade notes

Change `diffseal/diffseal@v0.3.1-beta` to `diffseal/diffseal@v0.4.0-beta`. Nothing changes for workflows that do not upload.

The evidence service is in private beta. The GitHub App can only be installed by invited organisations for now.
