# Diffseal v0.6.1-beta

Accuracy fixes from replaying 675 commits of 9 public Terraform repositories. False BLOCKs fell from 8 to 0, and no new BLOCKs appeared. `docs/STATUS.md` has the full numbers.

## Changes

- A change to an external module's `source` or `version`, or its removal, raises the gate to REVIEW and names the module, the old and new version, and the roots that use it. These changes used to pass.
- Symbolic links in the repository are followed. A link that leaves the repository or points at nothing is reported, not followed.
- A moved root directory is compared with its old directory. A deleted root lists its resources as likely deletions, destroyed only if someone runs `terraform destroy` against its state, instead of blocking.
- Absent and `null` arguments, provider defaults, and Optional and Computed arguments follow the provider's own rules before comparing, which removes false replacements.
- Var-files in or below a root are evaluated with that root. A changed tfvars file is still reviewed and named. Terragrunt is noted, not read.
- A narrowed IAM policy no longer raises `iam.least-privilege`.

## What to expect

More changes land in REVIEW than before (172 against 148 of the 675 commits), mostly external module bumps and var-file changes that used to pass.

## Upgrade notes

1. Change `diffseal/diffseal@v0.6.0-beta` to `diffseal/diffseal@v0.6.1-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.6.1-beta`.
2. Update the CLI with `npm install -g diffseal@beta`.

See CHANGELOG.md for all versions.
