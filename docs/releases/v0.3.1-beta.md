# TerraTrust v0.3.1-beta

This release shortens the PR comment. The analysis and the gate are unchanged.

## Changes

- The footer is one line: the TerraTrust version, the two commits compared and a link to the FAQ.
- A change whose action is likely rather than proven says so in its own row, as `update (likely)` or `update (unknown)`. This also holds when one row stands for several roots.
- The note that control IDs refer to ISO/IEC 27001:2022 Annex A moved to the FAQ.

## Upgrade notes

Change `TerraTrust/terratrust@v0.3.0-beta` to `TerraTrust/terratrust@v0.3.1-beta`. Anything that parses the footer text must be updated. Use the `gate` output or `--json` for automation.

See CHANGELOG.md for all versions.
