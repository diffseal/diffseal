# Diffseal v0.5.4-beta

Logging and security-service checks. The existing analysis and gate are unchanged.

## Changes

- New configuration checks on the resources each change touches, as configured in Terraform: CloudTrail logging, multi-region, log file validation and KMS key; VPC flow logs; CloudWatch log retention, including the `DELIVERY` class; S3 access logging. They cite SOC 2 CC7.2.
- A change that switches off or deletes CloudTrail, GuardDuty, AWS Config or Security Hub is flagged for review. These checks never block by default.
- Optional policy setting `minLogRetentionDays` in `.diffseal.json`.

## Upgrade notes

1. Change `diffseal/diffseal@v0.5.3-beta` to `diffseal/diffseal@v0.5.4-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.5.4-beta`.
2. Update the CLI with `npm install -g diffseal@beta`.

See CHANGELOG.md for all versions.
