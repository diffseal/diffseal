# Diffseal v0.6.4-beta

Three accuracy fixes found in review rounds after v0.6.3-beta, and a new Action name for the GitHub Marketplace. On the three measured sets, 2,175 commits, no gate changed and no BLOCK is judged false. `docs/STATUS.md` has the numbers.

## Changes

- Inline IAM policies. A user, role or group policy whose owner is named through a reference belongs to a principal only when that principal had the old name before the change and has the new one after. Before, either name was enough, so a policy moved onto a renamed principal could keep its findings as pre-existing and pass. It is now reviewed.
- Workspace names. A `substr()` of `terraform.workspace` takes the rest of the name only when its length is `-1` or the length of the workspace. Before, any `length()` counted, which built names that do not exist and hid resources limited to the real workspace. Such a length now builds no name, and the root gets a note.
- Lookups by an unknown key. A ForceNew attribute read from a map by a key not known statically keeps its possible replacement on every resource type, naming the keys whose value changes. Before, a type that is not stateful, such as an EC2 instance, lost it, so replacing the production instance passed.
- The Action is named "Diffseal Terraform review" in `action.yml`, because "DiffSeal" is taken on the Marketplace. Its description now reads "Review Terraform changes on AWS without running terraform or holding cloud credentials. Flags data that would be lost."

## What to expect

The same gates as v0.6.3-beta on the measured commits. A change that renames an IAM principal and moves an inline policy onto it, a workspace name cut by `substr()` with a length not known offline, or a ForceNew value picked per environment from a map can now be reviewed where it passed before.

## Upgrade notes

1. Change `diffseal/diffseal@v0.6.3-beta` to `diffseal/diffseal@v0.6.4-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.6.4-beta`.
2. Update the CLI with `npm install -g diffseal@beta`.

See CHANGELOG.md for all versions.
