# Diffseal v0.5.3-beta

The CLI is on npm. The analysis and the gate are unchanged.

## Changes

- Install the CLI with `npm install -g diffseal@beta`, or with Bun, Yarn or pnpm. Run it once without installing: `npx diffseal@beta verify ./pack --account your-org --period 2026-Q4`. Node.js 18 or later.
- `diffseal --version` prints the version.

## Upgrade notes

1. Change `diffseal/diffseal@v0.5.2-beta` to `diffseal/diffseal@v0.5.3-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.5.3-beta`.

See CHANGELOG.md for all versions.
