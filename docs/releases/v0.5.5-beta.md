# Diffseal v0.5.5-beta

Encryption checks in transit and at rest. The existing analysis and gate are unchanged.

## Changes

- New checks on the configuration each change touches: load balancer listeners, CloudFront, ElastiCache, OpenSearch and Elasticsearch, EBS and EFS. They cite SOC 2 CC6.7 or CC6.1 and warn at most.
- A check passes only when the configuration explicitly turns encryption on, and warns only when it explicitly turns it off with nothing enforcing it. Everything else is unknown. Known limits are in `docs/research/known-gaps.md`.
- DynamoDB `server_side_encryption { enabled = false }` now reads as an AWS-owned key, not as encryption switched off.

## Upgrade notes

1. Change `diffseal/diffseal@v0.5.4-beta` to `diffseal/diffseal@v0.5.5-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.5.5-beta`.
2. Update the CLI with `npm install -g diffseal@beta`.
