# Diffseal v0.7.0-beta

Change records now say what changed. On the three measured sets, 2,175 commits, no gate changed and no BLOCK is judged false. `docs/STATUS.md` has the numbers.

## Changes

- What changed per resource. Each updated or replaced resource in a change record lists the names of the top-level settings that changed, sorted, up to 32. For a short fixed list of operational settings, it also gives the old and new value: Lambda memory, timeout and reserved concurrency; RDS instance class, engine version and storage; EventBridge schedules and states. A value is kept only when it has the shape that setting allows, so a secret typed into one of them stays in CI. A sensitive value reads `(sensitive)`. Before, a routine update said only "update", and an auditor had to open GitHub to learn what changed.
- The upload section of the action guide says what the record carries per resource, and that findings can quote the value they are about. Source code, state, plan files and credentials are still never uploaded.

## What to expect

The same gates as v0.6.5-beta. Change records and evidence uploads carry the new `changed`, `changedMore` and `values` fields. The evidence service shows them on the record page, the auditor view and in signed packs.

## Upgrade notes

1. Change `diffseal/diffseal@v0.6.5-beta` to `diffseal/diffseal@v0.7.0-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.7.0-beta`.
2. Update the CLI with `npm install -g diffseal@beta`.

See CHANGELOG.md for all versions.
