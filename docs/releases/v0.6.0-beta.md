# Diffseal v0.6.0-beta

Diffseal reviews Terraform only. The application code check is removed.

## Changes

- Removed: the `check-app` command, the Action's `mode: app` with its `infra-path`, `role` and `entry` inputs, and the `diffseal_check_app` MCP tool. A workflow that still sets `mode: app` fails with "mode: app was removed in v0.6.0-beta; Diffseal reviews Terraform only", and `diffseal check-app` fails with "check-app was removed in v0.6.0-beta; Diffseal reviews Terraform only".
- `pr` mode and `replay` no longer scan application code added by a change, so a missing permission in application code no longer raises the gate to REVIEW.
- The parser grammars for Go, TypeScript, Python, Java, Kotlin and C# are gone, and the Action bundle falls from 3.1 MB to 1.0 MB.
- The `infra`, `roles` and `env` link settings in `.diffseal.json` are ignored if present. The `diffseal demo` app example is removed.
- Change records keep the required `access` field of `diffseal.change-record/v1`, always as an empty list, so the evidence service accepts them.

## Upgrade notes

1. Remove any step that sets `mode: app`, or switch it to `mode: pr` in the repository that holds the Terraform.
2. Change `diffseal/diffseal@v0.5.5-beta` to `diffseal/diffseal@v0.6.0-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.6.0-beta`.
3. Update the CLI with `npm install -g diffseal@beta`.

See CHANGELOG.md for all versions.
