# TerraTrust v0.4.1-beta

This release makes upload problems visible in the job log. The analysis and the gate are unchanged.

## Changes

- A rejected upload shows the service's reason and the failing field, for example `upload failed (400): Invalid field (pullRequest.headSha)`, not only the status code. Only plain characters from the response are printed.
- When the pull request or its base branch changed after the run started, the service stores the record as stale and leaves the `TerraTrust evidence` check unchanged. The Action now says so, and that a new push refreshes the check. Re-running the job does not help, because GitHub reuses the original event. No exception link is shown for a stale record.

## Upgrade notes

Change `@v0.4.0-beta` to `@v0.4.1-beta`, for both `TerraTrust/terratrust` and the reusable workflow `TerraTrust/terratrust/.github/workflows/upload.yml`.

See CHANGELOG.md for all versions.
