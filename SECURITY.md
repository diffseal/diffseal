# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Report them privately through GitHub's private vulnerability reporting on the [TerraTrust/terratrust security advisories page](https://github.com/TerraTrust/terratrust/security/advisories/new).

Include the steps or input needed to reproduce the issue and what version or commit you tested. TerraTrust is a one-person project, so expect a reply within a few working days.
