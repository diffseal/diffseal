# Diffseal v0.5.0-beta

TerraTrust is now Diffseal. The analysis and the gate are unchanged.

## Changes

- The repository is `diffseal/diffseal`. The CLI is `diffseal` and `diffseal-mcp`.
- The evidence service is `api.diffseal.com`, and the public key list is `https://diffseal.com/.well-known/diffseal-keys.json`. Packs are signed with the new key `d6ceaf99517d3d38`.
- Format ids start with `diffseal.`, the settings file is `.diffseal.json`, the module lock is `diffseal.modules.lock.json`, environment variables start with `DIFFSEAL_` and the MCP tools start with `diffseal_`.

## Upgrade notes

1. Change `TerraTrust/terratrust@v0.4.1-beta` to `diffseal/diffseal@v0.5.0-beta`, and the reusable workflow to `diffseal/diffseal/.github/workflows/upload.yml@v0.5.0-beta`.
2. Rename `.terratrust.json` to `.diffseal.json` and `terratrust.modules.lock.json` to `diffseal.modules.lock.json`, then run `diffseal modules fetch` again. Until you rename it, `.terratrust.json` is still read.
3. Install the Diffseal GitHub App. The check is now called `Diffseal evidence`: update any branch rule that requires the old check name.
4. Packs signed by TerraTrust do not verify with this version.

See CHANGELOG.md for all versions.
